# Calculator

A calculator project built while working through The Odin Project foundations.

## Current progress

- Added the calculator layout and number, decimal, operator, and equals buttons.
- Added a display area for the current calculation.
- Added styling for the calculator frame, display, buttons, and operator buttons.
- Added JavaScript functions for addition, subtraction, division, and multiplication.
- Added the initial `operate(n1, op, n2)` function for connecting an operator to two numbers.

## Project files

- `index.html` contains the calculator structure and controls.
- `style.css` contains the calculator layout and visual styling.
- `script.js` contains the arithmetic functions and calculator logic in progress.

The calculator is still being developed. Button event handling, a working display, and the remaining calculator behavior will be added next.
