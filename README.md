# Calculator

A small JavaScript calculator that demonstrates the four basic arithmetic operations:

- Addition
- Subtraction
- Division
- Multiplication

Each operation accepts two numbers, performs the calculation, and logs the result to the browser console.

## Example

```javascript
add(12, 12);
subtraction(12, 12);
division(12, 12);
multiply(12, 12);
```

Open the JavaScript file in a browser environment with developer tools enabled to see the results in the console.
